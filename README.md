# АристократЪ — редизайн

Адаптивный сайт гастробара в Уфе. Тёплая светлая палитра, винные акценты, шрифты Cormorant Garamond и Manrope, оригинальные фотографии заведения.

## Запуск

```sh
npm install
npm run dev -- --port 5186
```

## Содержимое

- 104 страницы, включая пагинацию отзывов, архив публикаций, события и предложения.
- 68 позиций основного меню, 211 позиций барной карты с 32 исходными разделами.
- `lib/content.json` содержит тексты и цены с https://aristocratbar.ru/, сохранённые 10 ноября 2026 года. Исправления исходных опечаток и актуализация цен не проводились.
- `public/assets/` содержит исходные фотографии, сканы отзывов и локальные шрифты.
- `components/site.tsx` — интерфейс; `app/globals.css` — оформление.
- `lib/page-content.ts` передаёт браузеру только данные текущей страницы.

Бронирование ведёт в исходный контакт MAX. Форма обратной связи в разделе контактов проверяет обязательные поля и согласие, затем открывает почтовое приложение с готовым письмом на адрес ресторана. Прямая серверная отправка не подключена; письмо отправляет посетитель в своём почтовом приложении. Карта использует исходный конструктор Яндекса. Отправка отзывов открывается на исходном сайте. Телефон, почта, социальные сети и ссылки на карты сохранены.

## Проверка и сборка

```sh
npx tsc --noEmit
npm run build
```

Публикация Sites использует конфигурацию `.openai/hosting.json` и поставляемый `sites()` Vite plugin. Исходный домен aristocratbar.ru этой сборкой не изменяется.
